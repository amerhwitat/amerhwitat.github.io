## Community discovery
Suitable public discovery channels include Reddit, DEV Community, Hashnode, Medium, Hacker News, Lobsters, CodeProject, Indie Hackers, Product Hunt, GitLab community spaces, and relevant YouTube/video communities.

Promotion should be manual or opt-in and must follow each platform's rules. Do not mass-post, spam comments, send unsolicited DMs, or attempt to bypass moderation. This directory provides stable project information that can be shared where self-promotion is permitted.

## Privacy
Private repositories are intentionally excluded. Never publish credentials, private keys, wallet recovery phrases, access tokens, CI secrets, or server credentials.
