Chimera II OS & OctavianOS — live ISO downloads

Two bootable amd64 live images, built from each repository's live-image/build.sh. Both boot BIOS and UEFI (GRUB 2.12), run a Debian 6.12.107 kernel with live-boot over an xz squashfs, auto-login as live (password live, passwordless sudo) into the project's own Aurora desktop rendered fullscreen by WebKit, and carry the 26 offline wallpapers below plus a verbatim source snapshot and offline app catalogs at /opt/aurora/repo and /opt/aurora/desktop. The latest rebuild fixes fullscreen sizing under Openbox at 1280×720 and 1920×1080; published checksums were re-verified against the assets on 3 November 2026.

Honest scope: these images run the Debian Linux kernel with the project's desktop, applications and userspace payload. They are not builds of the native Spit Fire/Koronos kernel and do not discharge the native userspace-handoff acceptance gates tracked in each repository's docs/ — read the release note before quoting them as proof of kernel readiness. Third-party catalog entries are not installed or certified applications.

Verify before booting: sha256sum -c against the released checksum, write with dd bs=4M if=… of=/dev/sdX status=progress oflag=sync (or any ISO-to-USB tool), then boot from it. GRUB offers “Live desktop”, “Classic X session (openbox)”, “Safe graphics (nomodeset)” and “Verbose boot”. Earlier 2026.11.02 builds remain available under the repositories' previous release tags.
