# Sliced default desktop icon artwork

The two supplied images are published here as the source sheets for individual concept UI icons used by the desktop gallery, the interactive web UI desktops, and the shared Chimera II OS / OctavianOS icon catalogue. These icons are **not runtime evidence**, installed icon themes, native desktop acceptance, or production release evidence.

## Original sheets

- Sheet A: `e96b2253-fb69-4f33-a675-aa245fa5a9f5.png` — 1536 × 1024 PNG, 1765497 bytes, SHA-256 `28d0203ccdbbcfddb52c5272d96a5ecad124cbe81f060edd7af2ab97e296f415`. Grid: 10 columns × 5 rows; each cell is cropped at 96 × 96 px.
- Sheet B: `4308a40a-64aa-403e-8eba-b586d1e911bf.png` — 1536 × 1024 PNG, 1749195 bytes, SHA-256 `a223d2e34fb83e2edc6f3e39421d334d0a115d9a72f8b370ff0b7eb6b4429c50`. Grid: 10 columns × 5 rows; each cell is cropped at 96 × 96 px.

Every cell was cropped deterministically with ImageMagick from the unmodified original. The complete catalogue mapping is in [ICON_MAP.json](ICON_MAP.json); every existing app icon ID now resolves to a supplied slice. Exact label matches are used where available, and catalogue entries without an exact sheet label use the closest supplied concept category (typically Advanced Tools).

Representative aliases previously published as `default-desktop-icon-a.png` and `default-desktop-icon-b.png` now contain the Settings and Files slices respectively, not letterboxed full-sheet images.
