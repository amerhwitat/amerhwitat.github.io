# Supplied Web UI desktop wallpapers

The six attached JPEG images are published here as selectable concept wallpapers for the interactive Web UI desktops, the FreeWin11/FreeXP previews and the desktop gallery. They are **not runtime evidence**, installed wallpapers, native desktop acceptance, or production release evidence.
