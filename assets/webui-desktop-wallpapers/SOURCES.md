# Supplied Web UI desktop wallpapers

The five newly attached JPEG images are published here as selectable concept wallpapers for the interactive Web UI desktops, the FreeWin11/FreeXP previews and the desktop gallery. The four earlier Web UI attachments (webui-03 through webui-06) and the two byte-identical Duck-ai variants already recorded as ref-10 and ref-11 complete all eleven supplied attachments in the 30-record Web UI mapping. These images are **not runtime evidence**, installed wallpapers, native desktop acceptance, or production release evidence.

Each original was copied byte-for-byte into `sources/` and deterministically cropped/resized to a 1920 × 1080 `previews/` JPEG with ImageMagick. The original SHA-256 and dimensions are recorded below and in [MANIFEST.json](MANIFEST.json).
