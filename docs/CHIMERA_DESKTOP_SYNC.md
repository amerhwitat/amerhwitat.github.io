# Chimera II Aurora Web Desktop

This site is an integration/deployment surface for the Chimera II Web desktop.

The canonical implementation is maintained in `amerhwitat/ChimeraIIOS` and uses Three.js/WebGL for the Aurora Wayland Glass environment with accessible HTML controls. Linux and Windows desktop profiles are represented visually; real host desktop access requires an explicitly authorized backend, VM or RDP service.

Canonical source: https://github.com/amerhwitat/ChimeraIIOS
