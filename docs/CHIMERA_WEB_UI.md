# Chimera II Public Web UI

The public Web UI presents the Chimera II Aurora desktop through a sandboxed Three.js/WebGL interface. It is synchronized conceptually with `amerhwitat/test` (integration/conformance) and `amerhwitat/ChimeraIIOS` (canonical OS implementation).

The UI supports Aurora, Linux desktop profiles and Windows desktop profiles as visual/adaptor profiles. It must not expose arbitrary host shell, filesystem, credentials, private keys, network, or native desktop-session access.
