# Portfolio 128D + P2P Index

This site is the public discovery/documentation surface for the Amer Hwitat portfolio.

The canonical Chimera semantic profile treats state as multidimensional and extensible, with geometry, time, observer/perspective, light/material response, events, objects, properties and interaction rules plus perception/cognition/vector extensions.

The canonical peer fabric is opt-in and authenticated. It uses identity/capabilities, deterministic envelopes, payload hashing, sequence/replay validation and optional signatures. Browser transports may use WebSocket/WebRTC without changing the logical protocol.

The protocol does not authorize unsolicited scanning, credential/private-key exchange, arbitrary executable transfer or remote command execution.

See `ChimeraIIOS/docs/` for the source-of-truth contracts.
