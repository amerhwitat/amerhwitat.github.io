CPU4096Simulator · Java runtime

Published project guide for the Java headless simulator core, assembler, instruction codec, memory bus, and cross-language contracts.

Scope: Java assembler and the expanded execution model are tested against shared Node/Java vectors. This is a host-side simulator contract, not a standardized ISA or proof of hardware execution.

Build and verify

cd java
mvn --batch-mode --no-transfer-progress clean verify

Implemented

  • 16-byte little-endian instruction encoding and decoding.
  • Source assembler with R/Z register aliases, decimal/hex/binary unsigned immediates, two-pass labels, and absolute byte-address JMP/JZ/JNZ.
  • Arithmetic, bitwise, multiply/high-multiply, shifts, rotates, division/remainder, comparisons, and privilege guards in the host-side CPU model.
  • Bounded memory bus with mapped permissions, execute checks, and W^X validation.
  • 19 shared Node/Java fixtures for selected arithmetic and data operations, plus focused Java/Node regression tests for label resolution, conditional branches, self-loops, duplicate labels, and undefined labels.

Still incomplete

  • Broader control-flow syntax, relative branches, call/return semantics, and exhaustive branch/flag/register-effect vectors.
  • Complete implementation of every catalog opcode and full flags/register-effect conformance.
  • Real MMU/TLB/DMA, hardware execution, and a complete fetch/decode/execute pipeline.
