Super Flash & ISO Tool

Desktop utility for disk-image inspection, hashing, carefully guarded removable-USB imaging, and Android ADB/Fastboot device diagnostics.

Capabilities

  • Inspect ISO/IMG/BIN/ROM file size, compute SHA-256, and compare an expected digest.
  • Read ISO9660 primary-volume metadata (volume ID, logical block size, declared size).
  • Create a Joliet ISO from a folder tree, then re-open its volume descriptor as a sanity check.
  • Enumerate USB disks on Windows and exclude boot/system disks.
  • Require exact disk-number confirmation, capacity validation, and a second destructive confirmation before writing.
  • Optional byte-for-byte read-back verification with progress.
  • Detect adb/fastboot tools and run read-only Android device preflight (model, fingerprint, boot/lock state where reported); no phone firmware is written.
Destructive operation warning

Raw disk writing erases data. Select only a removable USB disk you own and intend to overwrite. Back up important data. Run elevated only when needed. A generic image writer does not guarantee that a particular ISO is bootable.

Mobile firmware scope

Mobile devices require vendor- and model-specific flashing procedures, signed firmware, bootloader state checks, and often separate partition images. This tool currently diagnoses adb/fastboot devices only; it does not blindly flash arbitrary ROMs to phones. Model-specific workflows remain a separate implementation task and must check exact model, firmware signature, bootloader state, partition layout and recovery path before any write.
