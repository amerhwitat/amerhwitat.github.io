Included capabilities

  • ISO/IMG/BIN inspection and SHA-256 verification.
  • ISO9660 metadata inspection and Joliet ISO creation.
  • USB disk enumeration with boot/system disk exclusion.
  • Exact disk-number confirmation, capacity checks, and optional read-back verification.
  • Read-only ADB/Fastboot device diagnostics.
Destructive operation warning. Raw USB imaging erases the selected disk. Verify the disk number and capacity, back up its contents, and use only a removable drive you own and intend to overwrite. A generic image writer cannot guarantee that an image is bootable.

Mobile device support

The current mobile feature set performs read-only ADB/Fastboot diagnostics. It does not flash Android firmware or claim generic phone compatibility. A future write workflow must be device-specific and verify the exact model, signed firmware, bootloader state, partition layout, and recovery path before any write.
