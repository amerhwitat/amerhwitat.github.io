How to read this workbench

This page links to real source repositories and tracks GUI coverage conservatively. A repository link is not a web port; a preview is not a native OS app; a successful compile is not proof of runtime readiness. Language labels are shown only where known from project context; other stacks are explicitly marked for source inspection.

Conversion strategy: keep the existing CLI/API and core logic intact; add accessible React/TypeScript or framework-native front ends where they fit; use a static progressive-enhancement GUI for simple tools; keep secrets, private keys, credentials, and local documents in-browser unless a project explicitly needs a secure backend.
