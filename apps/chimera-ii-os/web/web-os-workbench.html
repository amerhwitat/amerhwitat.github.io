INSTALLATION & LIFECYCLE

Install or upgrade

This assistant prepares the workflow and opens the official project release pages. A static website cannot silently install an operating system, write a USB device, repartition disks, or upgrade a running native OS. Those steps require a downloaded, verified image and explicit action in a trusted installer.

01 · CHOOSE

ChimeraIIOS · Aurora

Live, installer and recovery artifacts are published only when the release gates pass.

Open official releases ↗Inspect build evidence
02 · VERIFY

Verify before install

  • Choose a release marked stable/accepted by the project.
  • Compare the published SHA-256 with the downloaded image.
  • Reject missing checksums, mismatched hashes, or candidate/probe-only images.
  • Back up data before changing disks.

No image selected. File hashing happens locally in your browser.

03 · INSTALL

Write installation media

  1. Use the project's documented installer or a trusted USB-writing utility.
  2. Boot the machine using BIOS or UEFI as supported by that release.
  3. Select Live/Installer and follow the on-screen storage confirmation.
  4. Reboot, then verify the installed system and retain the release checksum.

No raw disk write is attempted by this page. This avoids accidental data loss and browser permission bypasses.

04 · UPGRADE / RECOVER

Upgrade safely

  1. Back up personal data and export settings.
  2. Read release notes and migration warnings for your current version.
  3. Use the native updater/recovery media provided by an accepted release.
  4. After reboot, check system health and keep a rollback/recovery path.

RNN · CNN · LLM RESEARCH BRIDGE

AI Assistant

Chat runs in the browser. Use the optional WebLLM local model when WebGPU and network access are available, or connect a trusted OpenAI-compatible model server. The local RNN adapter can load the trained catalog model JSON from the OctavianOS CI artifact and generate character-level continuations; it is a small advisory model, not an instruction-tuned LLM. WebLLM runs an LLM when WebGPU/model download is available. Hosted RNN/CNN/LLM services can use the OpenAI-compatible endpoint. No trained CNN weights are bundled here.

Offline helper ready

WebLLM downloads model weights from its configured model source and may use substantial memory. Endpoint requests send your message history to that host. Do not enter secrets into a public/static page; no API key is stored here. For local RNN mode, download the OctavianOS trained-model workflow artifact, extract trained-command-isa-rnn.json, then select it above.
