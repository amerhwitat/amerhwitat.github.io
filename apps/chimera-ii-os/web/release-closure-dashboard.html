Diagnostic / smoke suite

Keep and run

Production acceptance suite

Separate suite required

Add a distinct suite that boots the production init/runtime from the final ISO, verifies real CPL3 syscalls and persistent PID 1, exercises disk persistence, installer rollback and recovery repair, captures six real BIOS/UEFI traces, and validates authenticated evidence provenance.

Do not rename, relabel or promote a probe to production acceptance. Synthetic traces belong only in verifier unit tests. A passing boot smoke, compile, ISO package or uploaded ZIP digest is not a certified ISO SHA-256 or release gate.
