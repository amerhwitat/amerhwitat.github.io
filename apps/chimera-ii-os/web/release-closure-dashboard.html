RELEASE DECISION: BLOCKED

No release may be tagged, merged as release-ready, or advertised as production-ready until one immutable ISO passes all six target/firmware cases and the real production DAPS evidence verifier. No successful production website deployment is confirmed by this status snapshot.

Process and filesystem

BLOCKED
  • Real process lifecycle and production execve/fork/wait/waitpid behavior.
  • Mounted production root filesystem and target init payload.
  • Same nonzero PID must produce the CPL3 syscall acknowledgement, readiness, and ring-3 file evidence.
  • Ring-3 OPEN/READ/CLOSE of /etc/os-release and successful writable /tmp operation.

Services and Aurora

BLOCKED
  • Production service manager must supervise real services and report meaningful exits.
  • Live session must start Aurora through the production path, not a contract marker.
  • Compositor/display/session health must be observed and tied to the accepted boot trace.

Installer

BLOCKED
  • Write and flush/sync a verified payload to the target disk.
  • Stop the first VM and cold-boot a distinct second VM/session from the same disk.
  • Verify readback bytes, range and digest; prove installed-system readiness in the second boot.

Recovery

BLOCKED
  • Run an actual repair operation against a defined fault.
  • Record precondition, operation, and independently checked postcondition.
  • Bind the evidence to the same immutable ISO and selected Recovery firmware trace.

AP / SMP

BLOCKED
  • Bring up secondary CPUs using the actual AP startup path and prove they are online.
  • Run independent tasks on distinct online CPUs.
  • Provide measured intervals on a shared monotonic timebase with genuine mathematical overlap; sequential callbacks do not qualify.

Release gate

BLOCKED
  • One immutable production ISO with a recorded SHA-256.
  • Six traces: Live, Installer and Recovery × BIOS and UEFI, all tied to that exact ISO.
  • Run production DAPS verifier over the real evidence bundle and retain its successful output.
  • Only then review release, merge, ISO publication and website claims.
