Safety

Allowlist boundary

BizXtreme documents an allowlist-only active network model and explicitly excludes hostile network automation.

  • No Internet-wide enumeration
  • No credential attacks
  • No evasion or spoofing
  • No exploitation workflow
Games

Multiplayer adapters

BizXtreme separates game rules from production transport so multiplayer implementations can be swapped without changing game logic.

  • Multiplayer session selection
  • Presence and peer directory
  • Deterministic game-state boundaries
  • Mobile and desktop targets
