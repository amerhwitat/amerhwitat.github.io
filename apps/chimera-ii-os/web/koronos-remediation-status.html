Plan / Do / Act / Check loop

  1. Plan: implement the process lifecycle before depending services on it. Define invariants for address-space ownership, context lifetime, PID identity, syscall ABI and cleanup.
  2. Do: implement process context creation/switch/return/exit/reap; add targeted unit and fault-injection tests. Keep unsupported paths fail-closed.
  3. Act: wire the actual production init ELF and payload for each target into PID 1/service supervision; then integrate desktop session launch and recovery/installer operations.
  4. Check: compile and run regression tests; execute real target/firmware boots; test installer cold reboot, recovery postconditions, desktop handshakes and physical AP concurrency. Fix failures and repeat.
  5. Release: rerun full ISO workflow, capture all six production traces for the exact final ISO SHA-256, and run the unchanged strict DAPS gate. Publish only after every mandatory gate passes.

Integrity rule: never synthesize readiness markers, replace production init with a probe ELF, weaken the verifier, or treat source inspection as runtime proof. A gate is PASS only when its required evidence exists and is tied to the tested build.
