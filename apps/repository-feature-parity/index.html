Acceptance rule

Mark a feature ported only after implementation, automated tests, browser smoke test, accessibility review, and deployed URL verification. Keep source license and dependency audit recorded. Native kernel, driver, mobile-permission, hardware, firmware and OS boot features remain native-only unless there is a real supported browser equivalent.

Framework choice: preserve static HTML/JS where effective; use React + TypeScript + Vite for new client-side tools; choose Next.js for server-rendering/server routes; use Angular or Vue for existing project fit rather than duplicate implementations.
