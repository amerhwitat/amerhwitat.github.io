Language coverage & execution contract

Language presence is based on GitHub repository metadata when available. A language entry is not proof that every file builds or runs. Native, compiled, GPU, OS-kernel, and dependency-heavy programs need their own toolchain, test suite, and security review. This browser page never executes repository code automatically.
