Migration rules

Aurora Wayland Glass Desktop remains the glass/workspace-oriented desktop; Marine Desktop remains the task-oriented desktop. Shared apps should use reusable web components while each desktop owns its shell, window behavior, permissions and theme.

Angular + TypeScript and Next.js + TypeScript are alternative web application targets, not a requirement to duplicate every app in both frameworks. Spring Boot requires a separately hosted JVM service; GitHub Pages serves static assets only. JavaFX/Swing and Python/native apps need an intentional browser port, WebAssembly build, or secured API bridge.

Acceptance contract for each port

  1. Inventoried: source entry points, language, dependencies, license and data flows identified.
  2. Ported: deliberate browser UI or documented native/API boundary; no “conversion” based on filenames alone.
  3. Build verified: language-specific build and automated tests pass.
  4. Browser verified: responsive, keyboard-accessible and error states tested; no unsafe dynamic code execution.
  5. Published: production URL responds and catalog/search index links to it.
  6. Native verified: separate native OS/JavaFX/Swing/runtime evidence where applicable.

GitHub Pages does not run Spring Boot, Python servers, native executables, or JavaFX desktop windows. Host those services separately and connect them through authenticated, narrowly scoped APIs; keep secrets server-side.
