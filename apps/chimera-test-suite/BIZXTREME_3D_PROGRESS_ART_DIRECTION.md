# BizXtreme 3D Progress and Aurora Library Art Direction

The web runtime should mirror the BizXtreme visual contract: extruded 3D progress indicators, Aurora cyan/violet glow, glass panels, and the user's Library artwork as the canonical visual reference.

Library references inspected for this integration:
- Aurora Wayland Desktop Showcase
- Chimera II OS Aurora Showcase

Use logical asset IDs and runtime derivatives rather than embedding large promotional images into every scene. Progress values should be shared with the game client and represented with depth, emissive highlights, and a restrained animation loop.
