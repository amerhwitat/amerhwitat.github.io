Thamudic / Ancient North Arabian Scanner

Research portal for photographing, segmenting, cataloguing and studying Ancient North Arabian inscriptions, including material historically grouped as Thamudic.

Architecture

Image → normalization → segmentation → glyph candidates → evidence record → optional classifier → scholarly verification → transliteration/translation

The baseline implementation is maintained in amerhwitat/nlp as thamudic_scanner.py. It does not require Tesseract or camel_tools.

Methodological rule

“Thamudic” is not treated as one uniform alphabet. Each record should retain script variety, corpus identifier, place/date, image provenance, candidate reading, confidence and scholarly verification status. Visual segmentation is not itself a translation.
