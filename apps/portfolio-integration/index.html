Recommended implementation stack

Existing static hub: retain HTML/CSS/JavaScript where it works. New interactive apps: React + TypeScript + Vite for client-heavy static tools and WebGL wrappers. Next.js: choose when server rendering, server routes or richer content workflows are needed. Angular and Vue remain valid app-specific targets, not mandatory duplicate ports.

Browser ports must document missing OS privileges, native APIs, dependencies, and any bridge service they require.

Release gates

  • Source and license discovered
  • Browser interaction implemented
  • Build and automated tests pass
  • Runtime smoke test recorded
  • Accessibility, mobile and security checks
  • Deployment URL and artifact verified

For OS repos, browser UI readiness is separate from BIOS/UEFI boot, real userspace handoff, Aurora startup and SMP acceptance.
