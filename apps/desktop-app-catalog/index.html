What native integration still requires

    The native application ecosystem acceptance gate remains blocked until per-target packages and launch, open-file, permissions, update, accessibility and runtime tests pass. Windows PE/Win32, Linux ELF/POSIX and macOS Mach-O/AppKit apps are not automatically binary-compatible.
