PDFreaderPY · Java tools

Published guide to Java PDF text extraction, literal text search, page rendering, and provenance-bearing ingestion.

Important: these Java tools process embedded selectable text. Scanned-page OCR is not performed and requires a separately configured provider.

Build and test

cd java
mvn --batch-mode --no-transfer-progress clean verify

Search selectable text

mvn org.codehaus.mojo:exec-maven-plugin:3.5.0:java \
  -Dexec.mainClass=io.amerhwitat.pdfreader.PdfTextSearch \
  -Dexec.args='document.pdf inscription --output matches.jsonl'

Results are JSON Lines with one-based page, line, and column metadata plus the matching line. Use --case-sensitive for exact case matching.

Extract a page range

mvn org.codehaus.mojo:exec-maven-plugin:3.5.0:java \
  -Dexec.mainClass=io.amerhwitat.pdfreader.PdfTextExtract \
  -Dexec.args='document.pdf --from 1 --to 3 --output extracted.txt'

Available Java components

  • Selectable text extraction by page range.
  • Case-configurable literal search across pages.
  • PDF page rendering and provenance record generation.
  • Native Swing reader GUI.
