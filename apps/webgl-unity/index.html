Publication checklist

  1. Copy the extracted webgl contents into apps/webgl-unity/.
  2. Keep compressed filenames and paths unchanged.
  3. Verify the host serves .gz assets with Content-Encoding: gzip; Unity WebAssembly should be delivered with the correct application/wasm content type.
  4. Run a real browser launch, fullscreen and console-error check before marking the app live.

GitHub Pages may not provide the custom response headers required by a Unity compressed build. If the player fails due to compression headers, rebuild with Unity decompression fallback or use a host/CDN that can set the required headers.
