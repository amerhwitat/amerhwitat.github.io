How this GUI works

Browse: every entry in the published catalog is searchable and links to the canonical repository path.

Preview: the selected file can be fetched read-only from its public raw source URL.

Run: only catalogued entrypoint candidates can be sent to http://127.0.0.1:8765/python/run. The local bridge must independently validate repo/path against its allowlist.

Build: sends a request to /python/build-all on the same local bridge. Results reflect that local environment only.

Convert: modules need capability-specific browser implementations and parity tests. Python imports, OS APIs, filesystem access, network access, crypto, OCR/ML dependencies and native extensions cannot be auto-translated safely by wrapping them in a web page.
