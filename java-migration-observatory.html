Parity rule: Java file counts are not conversion-completion percentages. Each port must preserve behavior, dependencies, error handling, security boundaries, and tests. Kernels, boot code, native drivers, browser UI, and hardware interfaces require platform-specific implementations or explicit native adapters.

Counts are observed .java file counts from completed public Git tree audits; they may include tests or vendored code. No exact count is fabricated for the two largest OS repositories.

Public repositories only. Private VanG is intentionally excluded. Audited 2026-10-16. Existing Java code does not imply build success unless a linked workflow confirms it.
