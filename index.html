Publishing model

This portal is the public-web discovery layer. Source remains on GitHub. Deep-web availability means resources reachable by direct URLs but not necessarily indexed by search engines; it is not a separate hosting network. Dark-web/onion publication requires a controlled Tor server and cannot be created by GitHub Pages alone.
