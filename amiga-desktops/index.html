Amiga Floppy Editions

Four profile-specific, bootable AmigaDOS floppy launch menus for classic Amiga emulators. Built as standard 880 KiB ADF images with an OFS filesystem and a 1.x-compatible boot block.

Compatibility scope: these are lightweight CLI desktop launch-menu editions for an Amiga 500-class 68000 with a legally obtained Kickstart 1.3 ROM. They are not full ports of the modern Aurora/Marine GUI desktops, and no Kickstart or Workbench ROM/software is bundled.

Build manifest and reproducibility

The deployment workflow builds each disk from its checked-in startup-sequence source using the open-source amitools xdftool, verifies the ADF size, AmigaDOS boot signature, filesystem contents and startup text, and writes SHA-256 hashes to the manifest.

Open build manifest

The images become available after the website deployment workflow completes successfully.

What the floppy contains

A bootable OFS volume, startup sequence, profile text, and emulator setup instructions. The boot sequence presents a text menu and leaves the Amiga CLI available for commands. It does not contain a native Koronos kernel, modern X server, browser engine, full Workbench, DOS application collection, or full modern desktop GUI.
